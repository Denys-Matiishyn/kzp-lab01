# Lab 1: Cross-platform Programming (Hotel Data Processing)

## Опис проєкту
Цей консольний Java-застосунок розроблено в рамках лабораторної роботи №1. Він читає записи про проживання гостей у готелі (Варіант 14), перевіряє їх на коректність, відкидає помилкові рядки та обчислює загальні показники.

## Предметна область (Варіант 14)
Формат одного запису у CSV файлі:
`guest;room;nights;nightlyRate;category`

Показники, що обчислюються:
* Загальна кількість ночей (Total nights)
* Загальний дохід (Total revenue)
* найдовше проживання

## Використання (CLI)
Програма підтримує такі параметри командного рядка:
* `--help` - вивести довідку
* `--version` - показати версію програми (1.0.0)
* `--input FILE` - вказати власний шлях до вхідного файлу CSV (за замовчуванням `data/input.csv`)
* `--output FILE` - вказати шлях для збереження текстового звіту (за замовчуванням `out/report.txt`)

**Приклад запуску зібраного проєкту:**
```bash
java -Dfile.encoding=UTF-8 -jar target/lab01-1.0.0-shaded.jar --input data/input.csv
```
