## 1. Тема, номер і варіант

## 2. Мета роботи
Ознайомитися з екосистемою Java, системою автоматизації збирання Maven, інструментами сталого тестування (JUnit) та контролю якості коду (SpotBugs). Навчитися читати дані з файлу, проводити їх валідацію, обчислювати статистику та налаштовувати процес безперервної інтеграції (CI) за допомогою GitHub Actions.

## 3. Постановка задачі
Створити програму для обробки записів клієнтів готелю з CSV-файлу.
* **Формат запису:** `room;guest;nights;nightlyRate;category`.
* **Чотири показники звіту:**
    1. Total valid records (загальна кількість коректних записів).
    2. Total nights stayed (загальна кількість проведених ночей).
    3. Total revenue (загальний дохід готелю).
    4. Maximum nights by a single guest (найбільша кількість ночей, проведених одним гостем).

## 4. Структура програми
* **Пакети:** `ua.lpnu.kzp` — основний пакет програми.
* **Файли:**
    * `Main.java` — головний клас, який містить логіку розбору аргументів командного рядка (`--input`, `--output`), читання файлу, валідації кожного рядка, обчислення статистики та запису результатів.
    * `MainTest.java` — клас із модульними тестами (JUnit 5) для перевірки логіки на крайових випадках.
* **Потік даних:** Вхідний файл (`data/input.csv`) зчитується по рядках. Кожен рядок розбивається масивом `split(";", -1)` (для збереження порожніх колонок). Дані проходять жорстку валідацію (перевірка порожніх полів, від'ємних чисел, `NaN`/`Infinity`). Коректні рядки додаються до загальної статистики. Результат виводиться в консоль та записується у файл (`out/report.txt`).

## 5. Інфраструктура
* **Система збирання:** Maven.
* **Залежності:** `junit-jupiter` (версія 5.x) для написання та запуску Unit-тестів.
* **Аналізатор:** `spotbugs-maven-plugin` налаштований у фазі `verify` для статичного аналізу коду.
* **Пакування:** Використовується `maven-shade-plugin` або `maven-jar-plugin` для генерації виконуваного файлу `lab01-1.0.0.jar`.
* **CI/CD (Рівень 3):** Налаштовано GitHub Actions (`ci.yml`), який автоматично виконує `mvn verify` при кожному push та pull request у гілку `main`, генеруючи відповідні артефакти та перевіряючи код аналізатором.
