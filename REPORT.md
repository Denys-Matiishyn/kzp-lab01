
# Звіт з лабораторної роботи №1

## 1. Завдання
Розробити кросплатформну консольну Java-програму для обробки даних предметної області "Готель" (Варіант 14). Налаштувати автоматичну збірку за допомогою Maven, додати модульні тести (JUnit 5), перевірку статичним аналізатором (SpotBugs) та налаштувати CI-пайплайн через GitHub Actions для ОС Ubuntu, Windows та macOS.

## 2. Реалізація
* **Логіка:** Основна логіка розташована у класі `Main.java`. Програма читає CSV файл, валідує вхідні записи (перевіряє наявність 5 полів, правильність числових типів та наявність імені гостя). Пошкоджені рядки пропускаються з виведенням логу помилки.
* **Кросплатформність:** Для забезпечення стабільної роботи на різних ОС усі консольні логи виводяться англійською мовою. При читанні та записі файлів жорстко задано кодування UTF-8 (`StandardCharsets.UTF_8`), що дозволило усунути вразливість `DM_DEFAULT_ENCODING`, виявлену аналізатором SpotBugs.
* **Тестування:** Реалізовано 9 модульних тестів у класі `MainTest.java`, які на 100% покривають вимоги лабораторної роботи: коректні дані, порожні файли, нечислові значення, перевірку українських символів у UTF-8 та обробку CLI-аргументів.
* **Пакування:** Використано `maven-shade-plugin` для генерації виконуваного FAT JAR архіву.

## 3. Результати
* Статичний аналізатор SpotBugs успішно проходить перевірку (0 bugs).
* GitHub Actions автоматично тестує код на платформах `ubuntu-latest`, `windows-latest` та `macos-latest`. Усі матричні джоби проходять успішно.
* Скомпільовані JAR файли автоматично публікуються як артефакти у GitHub Actions.
